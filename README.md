# Buggy Calculator

A simple Python calculator library with utility functions and input validation.

## Setup

```bash
pip install -r requirements.txt
```

## Run Tests

```bash
pytest -v
```

## Project Structure

```
src/
├── calculator.py    # Core arithmetic operations
├── utils.py         # Formatting & helper utilities
└── validator.py     # Input validation
tests/
├── test_calculator.py
├── test_utils.py
└── test_validator.py
```
